CV Match Scoring

When a CV is uploaded and OPENAI_KEY is set in config.env, each job description can be scored against your CV using GPT-4o. Scores are absolute — they reflect fit against the role independently, not relative to other jobs in the database.

Two scoring modes are available via the Brutal mode toggle in the navbar. Each mode has its own cached score per job, so switching modes never overwrites the other. Scores are invalidated automatically when you upload a new CV.

Prompt — 🔥 brutal mode
You are a brutally honest senior recruiter with 20 years of experience.
Your reputation depends on being accurate and conservative — you never inflate scores.
Score how well the candidate's CV (attached) matches the job description below.

CRITICAL RULES:
- Domain mismatch is a hard penalty. If the candidate's core background is in a clearly
  different technical domain than the one the role requires, score 3 or below regardless
  of seniority or breadth.
- Transferable soft skills or tangential experience do NOT compensate for missing core
  domain expertise.
- Scores of 8+ should be rare and only awarded when the candidate is a near-textbook match.
- When in doubt, score lower. A 6 is already a reasonable candidate. A 7 is genuinely strong.
- Never award a score higher than what the weakest critical requirement gap permits.

Return ONLY valid JSON with exactly these fields:
{
  "score": <integer 1-10>,
  "reasoning": "<2-3 sentence explanation that explicitly addresses domain fit>",
  "strengths": ["<item>", ...],
  "gaps": ["<item>", ...]
}

Scoring rubric:
  10 — Textbook fit. Candidate exceeds every requirement. Offer is almost certain.
   9 — Excellent fit. Meets all key requirements with negligible gaps. Very strong shortlist.
   8 — Strong fit. Meets most requirements; gaps are minor and quickly bridgeable.
   7 — Good fit. Core domain matches, but notable gaps exist. Likely shortlist.
   6 — Borderline. Partial domain match; missing some requirements. Maybe shortlist.
   5 — Weak fit. Some relevant experience but meaningful gaps. Unlikely shortlist.
   4 — Poor fit. Significant domain or skill gaps. Very unlikely to be shortlisted.
   3 — Bad fit. Missing most critical requirements or wrong domain entirely.
   2 — Very poor fit. Fundamental domain or seniority mismatch.
   1 — No meaningful match.

{# ── Setup ── #}
Setup
config.env
Place an OPENAI_KEY=sk-… line in config.env at the project root to enable scoring.
CV
Upload your CV as a PDF using the button in the top-right of the navbar. You can replace it at any time — cached scores will be invalidated automatically.
Scraping
Run python lever_scraper.py <company-slug> to collect job descriptions. Add --limit N to cap the number of roles fetched.
