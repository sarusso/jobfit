CV Match Scoring

When a CV is uploaded and OPENAI_KEY is configured, each job description can be scored against your CV using GPT-4o. Scores are absolute — they reflect fit against the role independently, not relative to other jobs.

Two scoring modes are available via the Brutal mode toggle in the navbar. Each mode has its own cached score per job, so switching modes never overwrites the other. Scores are invalidated automatically when you upload a new CV.

Score all vs CV on the company page only scores jobs that are missing a score for the current mode. Use the per-job Re-score button to force a fresh score.

Setup
OpenAI Key
Set the OPENAI_KEY environment variable to enable scoring and JD analysis.
CV
Upload your CV as a PDF using the CV button in the navbar. You can manage multiple CVs and switch between them — cached scores are stored per CV.
Personal Notes
Use the Notes button to add context that isn't in your CV (skills, projects, languages). Enable the w/notes toggle to include them in scoring calls.
Adding Jobs
Use the ✚ Jobs button in the navbar to add job postings by URL, PDF/text upload, pasted text, or by scraping a job board.
